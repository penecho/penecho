# Motion scene contract (General HTML)

For animation, a step-by-step animated explanation, a 2D physics simulation or a static or rotating 3D illustration, prefer a scene over hand-written HTML whenever the vocabulary below fits. PenEcho validates the scene and renders it with its own pinned runtime (anime.js, matter-js, Zdog), so you write a few dozen lines instead of a full document, and later refinements patch only those lines. Return exactly one command:

`{tool:"html_widget",pluginId:"general",x,y,w,h,title,sourceFormat:"penecho-scene+json",scene:{...}}`

Pass `scene` as a JSON object, never as a string, and omit `html` and `copyText`. Coordinates are in the scene's own `size` space (default `[960,540]`, top-left origin), which PenEcho scales to the Widget. Colors are hex values or tokens: accent, ink, muted, blue, red, green, orange, purple, teal, yellow, pink, gray, white, black, paper, none. Keep the background transparent unless the user asks otherwise. Common scene options: `speed`, `loop`, `controls` (default true: replay, pause, speed).

- `engine:"motion"` (default): `actors` and `beats`.
  - Every actor has a unique `id` and a `type`: rect `{x,y,w,h,r}`, circle `{x,y,r}`, ellipse `{x,y,rx,ry}`, line and arrow `{from:[x,y],to:[x,y]}`, path `{d}` (SVG path data), polyline and polygon `{points:[[x,y],...]}`, text `{x,y,text,size}` (x,y is the text center; `anchor` start/middle/end), axes `{box:[x,y,w,h],x:[min,max],y:[min,max],grid,xLabel,yLabel}`, fn `{axes:"<axes id>",expr:"sin(x)"}` (math in x, no JavaScript), and group `{children:[ids]}` to move parts together. Style with `fill`, `stroke`, `width`, `opacity`, `dash`. `hidden:true` starts an actor invisible.
  - `beats` play in order. Each beat has an optional one-line `caption` in the user's language and `steps` that run in sequence; `with:true` starts a step together with the previous one. Every step has `do`, `target` (an id or a list of ids), and optional `dur` (seconds, default 0.8), `delay`, `stagger` and `ease` (linear, inOutQuad, outCubic, inOutSine, outBack, outElastic, outBounce and similar).
  - Steps: `draw` (stroke draws on), `fadeIn`, `fadeOut`, `appear`, `hide`, `write` (text types itself), `count {from,to,decimals,prefix,suffix}`, `move {to:[x,y]}` or `{by:[dx,dy]}` or `{along:"<path, fn or line id>",range:[0,1]}`, `scale {to}`, `rotate {to}` (degrees), `pulse`, `color {fill,stroke}`, `morph {to:"<path id>"}` (path to path), `camera {zoom,center:[x,y]}` or `{zoom,target}`, and `wait`. An actor whose first step is draw, fadeIn, appear, write or count starts hidden automatically.
- `engine:"physics"`: `bodies` (`shape` circle `{x,y,r}`, rect `{x,y,w,h}`, polygon `{x,y,sides,r}`, segment `{x,y,to:[x,y]}` which is static; optional `static`, `angle`, `restitution`, `friction`, `density`, `velocity:[vx,vy]` in px/s, `fill`, `label`, `trail:true`), `constraints` (`{a,b}` between bodies or `{a,anchor:[x,y]}` to a fixed point; `length`, `stiffness`, `render:"line"|"spring"`), `gravity:[x,y]` (default `[0,1]`), `walls:"box"|"floor"|"none"`, `labels:[{text,x,y}]`, and `duration` in seconds.
- `engine:"3d"`: `shapes` with `type` box `{width,height,depth,faces:{top,front,...}}`, sphere `{diameter}`, cylinder and cone `{diameter,length}`, hemisphere, torus `{diameter,stroke}`, ellipse, rect, polygon `{radius,sides}`, line and path `{path:[[x,y,z],...]}` and group. Each shape takes `translate:[x,y,z]`, `rotate:[x,y,z]` in degrees, `color`, `stroke` and `parent` (a group id). The origin is the center. `spin:[x,y,z]` is the idle rotation in degrees per second, `view` the initial rotation, `zoom` the scale, and users can drag to rotate.

Example: `{"engine":"motion","actors":[{"id":"ax","type":"axes","box":[80,60,800,420],"x":[-4,4],"y":[-2,2]},{"id":"f","type":"fn","axes":"ax","expr":"sin(x)"},{"id":"p","type":"circle","x":80,"y":270,"r":12,"fill":"orange"}],"beats":[{"caption":"Axes","steps":[{"do":"draw","target":"ax"}]},{"caption":"y = sin x","steps":[{"do":"draw","target":"f","dur":1.2}]},{"caption":"A point rides the curve","steps":[{"do":"move","target":"p","along":"f","dur":2}]}]}`

Use hand-written HTML instead only for behavior outside this vocabulary, such as live data, typed input, custom tools or rich layouts.
