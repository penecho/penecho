Practice exam · Limits and derivatives

Six questions from Class 1 and Class 2, easiest first. Write your answer under each one, then open its answer.

1Limits
Find
limx→3(2x2 − 5)
your answer

Worked answer

The function is continuous, so plug in: 2 · 3² − 5 = 18 − 5.

= 13

2Limits
Find
limx→2x2 − 4x − 2
your answer

Worked answer

Plugging in gives 0/0. Factor: x² − 4 = (x − 2)(x + 2), so the fraction is x + 2 for x ≠ 2.

Then plug in: 2 + 2.

= 4

3Limits
Find
limx→0sin 5xx
your answer

Worked answer

Write it as 5 · sin(5x) / (5x). With u = 5x, u → 0 too, and sin u / u → 1.

= 5 · 1 = 5

4Derivatives
Find f′(x) for
f(x) = 4x3 − 2x + 7
your answer

Worked answer

Power rule on each term: (4x³)′ = 12x², (2x)′ = 2, and a constant gives 0.

f′(x) = 12x² − 2

5Derivatives
The tangent line to
y = x3 at x = 1
your answer

Worked answer

f(1) = 1 and f′(x) = 3x², so f′(1) = 3.

y = f(1) + f′(1)(x − 1) = 1 + 3(x − 1).

y = 3x − 2

6Derivatives
From the definition, find f′(x) for
f(x) = 1x
your answer

Worked answer

[1/(x+h) − 1/x] / h = [x − (x+h)] / [h · x(x+h)] = −1 / [x(x+h)].

As h → 0 this goes to −1 / x².

f′(x) = −1 / x²
