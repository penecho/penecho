# Timeline app

A small web page that shows a team's week as lines: one row for each thing being worked on, with a dot for each step.

Open `index.html` in a browser. There is nothing to install.

- `data.js`: the projects, their lines, their steps and their files
- `home.js`: draws the homepage: projects, the week, the lines on one trunk, the latest files
- `style.css`: how it looks
