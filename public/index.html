Markdown + LaTeX

Type normally; Markdown and likely LaTeX are formatted automatically when confirmed. Preview shows the result.

  • Use # for headings, - for lists, **text** for bold, and *text* for italic.
  • Common bare TeX such as \pi, \frac{a}{b}, A_x, and \sin(x) is recognized without $ delimiters.
  • Press Ctrl/Cmd + Enter to confirm.

**Speed:** $v=\frac{d}{t}$

    What's new 0.9.0

    Refine, projects, and flexible AI connections

    Version 0.9.0 adds guided in-place editing, project-based shared canvases, and a more flexible and dependable AI workflow.

    0.9.0

    • Save up to ten API or CLI connections, start from Kimi and MiniMax presets, test them in Canvas, and switch the active connection for this device with one click.
    • Organize shared server canvases into projects and browse larger previews by modification time. Versioned v2 bundles keep every canvas asset together while remaining compatible with existing saves.
    • Write or place instructions anywhere in the current viewport, choose the widget to update, and apply a standard unified diff that reduces tokens while preserving confirmation, undo, and pending instructions after failure or cancellation.
    • API requests now use true SSE streaming, reducing long silent waits, improving responsiveness, and keeping lengthy model responses more stable through compatible gateways.
    • The top status area now shows each request stage, live response receipt, retries, long-wait notices, and cancellation; the magic button can stop active requests immediately.

    Earlier highlights

    • 0.8.1 added live public-data access for General HTML widgets and SVG-first animation and complex graphics.
    • 0.8.0 and earlier added editable professional diagrams, server-backed canvas storage, clipboard workflows, sourced web photos, and more reliable editing and export.
