PenEcho 项目架构

PenEcho：AI 驱动的可视化 Canvas 工作区——浏览器客户端、Node.js 服务、内置/外部 Agent、模型执行器与云端协同。

浏览器客户端桌面端Node.js 服务AI / 模型MCP / 外部 Agent云服务

Canvas AI 一次请求

  • 脏区 bbox + 8×8 热点网格 + 焦点放大
  • 服务端校验几何 / 图像 / 插件 / Origin / Cookie
  • Sharp 无损 WebP，API 拒绝时回退 PNG
  • NDJSON 进度：打包 → 提交 → 模型 → 校验，可随时停止

模型执行与安全边界

  • API 凭据只存在于 Node 进程
  • CLI 子进程使用独立临时 HOME，不含 PenEcho 密钥
  • CLI 模式需 Host / Origin / Cookie 校验后才启动
  • 停止按钮把取消传播到上游请求

两条 Agent 通路

  • 内置 Agent：Agent 面板 ↔ canvas-agent 运行时
  • 外部 Agent：Local MCP（stdio/HTTP）或 Cloud MCP（HTTPS）
  • 仅显式启用的 Canvas 可被发现
  • 能力：读取、截图、编辑对象、补丁源、接收反馈

状态与数据

  • IndexedDB：snapshots + snapshot-tiles（瓦片 PNG）
  • ~/.penecho：connections.json、config.env、请求 traces
  • Canvas 虚拟源以 contentHash 严格补丁
  • 桌面端状态目录 = Electron userData

拓扑依据 docs/architecture.md 与源码目录（src/、public/、desktop/）

Cloud 与外部 MCP 连接均为可选路径

省略辅助模块：tour / viewer / summon 等 UI 扩展与构建脚本

对照：当前自动策略，横向折行
