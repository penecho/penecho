读链路为什么不让客户端直连数据库

混合文档测试样本 A6：普通 HTML 讲解 + 内嵌 architecture 语义图形（同文档、无 iframe）

下面的图不是图片，而是内嵌在 HTML 里的 data-penecho-architecture 语义 JSON，由浏览器端本地渲染器布局。正文与图形共享同一套 domain 配色，读者可以按颜色把讲解和图对上。

为什么这么设计

  • 凭据只存在于服务端，客户端被攻破不会直连数据库。
  • 缓存层吸收突发流量，落库 QPS 与入口 QPS 解耦。
  • 读副本承担复杂查询，主库只服务写入。
