PenEcho MCP 架构 · 本地自动布局

同一份语义数据：模型提供实体、边界和关系；浏览器负责布局、连线和展示。

调用方桥与传输Node 宿主职责规则与绑定浏览器执行可选能力

stdio 桥与发现

  • 轻量桥接进程，不启动完整 PenEcho 应用。
  • 读取本机凭据与发现缓存，经 HTTPS /mcp 复用连接。
  • HTTP 空闲清理不终止仍打开 stdin 的桥；恢复连接不自动重放已提交的写请求。

接入与画布分派

  • HTTPS listener 负责认证与传输会话。RPC 校验工具输入，分派到目标浏览器与文档。
  • 图片上传和工具调用共享 HTTPS 接入；不同端口候选不代表多台服务器。
  • 共用画布操作管理版本、hash、幂等和虚拟文件读写。

规则与会话绑定

  • guidance 是独立只读分支，不经过画布执行队列。
  • client/sessionKey 映射到 canvasId/documentId，持久绑定存储在 Node 侧。
  • 浏览器连接 ID、文档 ID、业务 sessionId 和 HTTPS session ID 互不相同。

浏览器文档与渲染

  • 授权浏览器通过 WebSocket /api/mcp/canvas 接收 call，返回 result、截图和错误。
  • 文档和快照由浏览器持有；Widget 在同一个沙箱 iframe 中渲染。
