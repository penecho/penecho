# 用户新增验收要求（v5 起）

1. 主图颜色必须表达可辨认的角色/分组，同一组件的详情沿用该颜色，支持快速对应；名称仍须可见。
2. 先调整相关节点位置，使连线尽可能水平或垂直；其次使用清晰的正交折线，仅在确有必要时采用斜线。
3. 字被遮挡、文字相互重叠均不合格，不因整体美观而豁免。
4. 保留所有历史图、请求、原始输出和审查结果，允许分开建立多个测试画布。新版本不覆盖旧版本。

这些要求仅用于架构图。本次实验的评分维度保持可追溯；v5 及以后另记录上述颜色、走线和文字硬性条件，不能把新条件悄悄套入旧评分后声称历史分数可直接比较。
