  <div class="detail">
    <div class="card c-browser">
      <h3>浏览器</h3>
      <ul>
        <li>前端代码 <code>src/client/app/</code>，构建产物为 <code>public/app.js</code></li>
        <li>画布：20000×20000 逻辑坐标，512×512 稀疏瓦片</li>
        <li>快照存于自身 IndexedDB，与 Node 服务持有的数据归属不同</li>
        <li>MathJax 由浏览器直接访问 jsDelivr CDN</li>
      </ul>
    </div>
    <div class="card c-node">
      <h3>Canvas AI 请求管线</h3>
      <ul>
        <li>服务端代码 <code>src/server/main.js</code></li>
        <li>经模型适配器选择后端：<code>src/providers/</code> 提供 <code>api</code>、<code>codex-cli</code>、<code>claude-cli</code>、<code>kimi-cli</code></li>
        <li>模型凭据只留在服务端，不进入浏览器</li>
      </ul>
    </div>
    <div class="card c-node">
      <h3>Canvas Agent 与 MCP 服务</h3>
      <ul>
        <li>Canvas Agent：<code>src/server/canvas-agent/</code>，经 WebSocket 与浏览器通信，使用模型连接与文档工具</li>
        <li>MCP 服务：<code>src/server/mcp/</code>，经已授权浏览器通道读写同一 Canvas，不经过 Canvas AI 的模型适配器</li>
      </ul>
    </div>
    <div class="card c-node">
      <h3>本地 Node 服务</h3>
      <ul>
        <li>静态资源 / HTTP API / Canvas AI / Canvas Agent / MCP 是同一本地服务中的不同职责</li>
        <li>服务端持有 <code>connections.json</code> 与请求日志</li>
      </ul>
    </div>
    <div class="card c-launch">
      <h3>启动入口</h3>
      <ul>
        <li>Electron 主进程加载本地服务器并打开浏览器窗口</li>
        <li>CLI 可启动同一服务器，是另一种入口</li>
      </ul>
    </div>
