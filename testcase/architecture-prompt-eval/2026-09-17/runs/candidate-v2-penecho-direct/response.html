ACanvas AI 请求管线

绘图主路径：一次请求返回结构化指令，用户确认后上画布。

浏览器交互→ POST /api/ai/command→ 模型适配器→ 外部模型 / CLI→ 结构化绘图指令→ 草稿展示 → 用户确认
  • 适配器：src/providers/ 提供 api、codex-cli、claude-cli、kimi-cli
  • 凭据仅在服务端；浏览器不接触模型密钥

BCanvas Agent 通道

面向长任务的多轮协作通道，独立于 AI 请求管线。

浏览器⇄ WebSocket⇄ Canvas Agent⇄ 模型连接
  • Agent 自带模型连接与文档工具，可自主完成任务
  • 代码位于 src/server/canvas-agent/

C外部 MCP Agent 路径

第三方 Agent 以 MCP 客户端身份接入本地 MCP 服务。

外部 AI Agent（MCP 客户端）→ HTTPS MCP→ MCP 服务→ 读写 Canvas
  • 经已授权浏览器通道操作画布
  • 不经过 Canvas AI 的模型适配器
  • 代码位于 src/server/mcp/
