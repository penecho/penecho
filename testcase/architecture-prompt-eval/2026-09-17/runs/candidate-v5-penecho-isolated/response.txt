          <li>画布：<code>20000×20000</code> 逻辑坐标 + <code>512×512</code> 稀疏瓦片</li>

        </ul>
      </div>
      <div class="card" style="border-left-color:#0f766e">
        <h3><span class="dot" style="background:#0f766e"></span>本地 Node 服务</h3>
        <ul>
          <li>服务端入口 <code>src/server/main.js</code>；四类职责在同一服务内</li>
          <li>Agent <code>src/server/canvas-agent/</code>，MCP <code>src/server/mcp/</code></li>
          <li>持有 <code>connections.json</code> 与请求日志</li>
          <li>模型凭据只存在于服务端，不进入浏览器</li>
        </ul>
      </div>
      <div class="card" style="border-left-color:#7c3aed">
        <h3><span class="dot" style="background:#7c3aed"></span>模型与 Agent 通道</h3>
        <ul>
          <li>模型适配器位于 <code>src/providers/</code>：<code>api</code>、<code>codex-cli</code>、<code>claude-cli</code>、<code>kimi-cli</code>（CLI 为本地子进程）</li>
          <li>Canvas AI 返回结构化绘图指令，浏览器展示草稿，由用户确认</li>
          <li>外部 MCP Agent 经 HTTPS 调用 MCP 服务；MCP 服务经已授权浏览器通道读写同一 Canvas，不经过 Canvas AI 模型适配器</li>
        </ul>
      </div>
      <div class="card" style="border-left-color:#64748b">
        <h3><span class="dot" style="background:#64748b"></span>启动入口</h3>
        <ul>

          <li>CLI 也可启动同一本地服务器，是另一种启动入口</li>
        </ul>
