AAI 绘图请求链路

一次“AI 画图”从用户到草稿的完整路径：

浏览器HTTP POST /api/ai/command
→
Canvas AI 管线模型适配器路由
↓
src/providers/api · codex-cli · claude-cli · kimi-cli
↓
返回结构化绘图指令浏览器展示草稿 → 用户确认
  • 模型凭据只保存在服务端，不进入浏览器
  • CLI 适配器以本地子进程方式调用

BCanvas Agent 与 MCP 协同

两条进入画布的独立通道：

Canvas Agent外部 MCP Agent
身份本地服务组件外部 MCP 客户端
协议WebSocket（浏览器↔Agent）HTTPS MCP 调用
能力模型连接 + 文档工具经已授权浏览器通道读写 Canvas
MCP 写入 Canvas 不经过 Canvas AI 模型适配器，是独立授权路径。
