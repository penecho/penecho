电商服务架构（给定设计）

示例设计 · 非特定云厂商 · 用于技术讲解
3 个微服务 3 个数据库 · 1 缓存 · 1 消息队列 2 个 Worker（幂等消费） 外部网络：CDN · 邮件供应商 同一私有网络：应用区 + 数据区
同步调用（HTTPS） 异步事件（消息队列） 数据访问 跨网络边界 应用区 私有数据区 外部网络

A同步路径（HTTPS）

  • 用户 → CDN：获取前端静态资源
  • 用户 → 公网 LB → API Gateway：私有应用区的统一入口
  • Gateway 扇出调用商品 / 订单 / 账户三个服务；三者并行独立，并非串联流水线

B异步链路（消息队列）

  • 订单服务下单后向消息队列发布订单事件
  • 库存 Worker 消费订单事件 → 更新库存数据库 → 发布处理结果
  • 通知 Worker 消费处理结果 → 调用边界外的邮件供应商
所有 Worker 必须幂等消费：同一事件重复投递不产生副作用。

C边界与约束

  • 同一私有网络：应用区与数据区均在其内
  • 网络之外：CDN 与邮件供应商
  • 数据区无公网入口：数据库、缓存、消息队列仅限内网访问
  • 订单状态：统一通过订单服务查询，不直连订单数据库
