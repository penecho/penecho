PenEcho 项目架构

浏览器 Canvas · 本地 Node 服务 · 外部模型 · MCP Agent
单一本地服务 · 多职责 画布 20000×20000 草稿 → 用户确认 模型凭据不进入浏览器

实现细节索引

前端src/client/app/ 构建产物输出到 public/app.js
画布模型20000×20000 逻辑坐标；512×512 稀疏瓦片按需加载
模型适配器src/providers/：api · codex-cli · claude-cli · kimi-cli
服务端服务 src/server/main.js · Agent src/server/canvas-agent/ · MCP src/server/mcp/
安全边界模型凭据仅存在于 Node 服务端，不进入浏览器
存储归属Node 服务：connections.json、请求日志；浏览器：自有 IndexedDB 快照

关键路径：浏览器 → HTTP /api/ai/command → AI 管线 → 外部模型 → 结构化指令 → 浏览器草稿 → 用户确认；浏览器 ⇄ WebSocket → Canvas Agent；外部 Agent → HTTPS MCP → MCP 服务 → 已授权浏览器通道 → 同一 Canvas。
