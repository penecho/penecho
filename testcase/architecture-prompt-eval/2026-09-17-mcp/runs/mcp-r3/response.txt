    <div class="panel" style="border-top-color:var(--teal)">
      <span class="tag">详情 A · 对应主图「stdio 桥接」</span>
      <h3>stdio 桥接 client.js</h3>
      <ul>
        <li>源码 <span class="mono">session-client.js</span>，分发名 <span class="mono">client.js</span>，不是完整 PenEcho 应用</li>
        <li>读共享主机凭据与发现缓存，校验 TLS，HTTPS <span class="mono">/mcp</span>，复用连接</li>
        <li>stdio 生命周期 · 会话恢复 · 有界并发</li>
        <li>HTTP 空闲清理<b>不终止</b>仍打开 stdin 的桥；下次调用重连并恢复原文档，不盲目重放可能已提交的写请求</li>
      </ul>
    </div>
    <div class="panel" style="border-top-color:var(--orange)">
      <span class="tag">详情 B · 对应主图「Node 宿主」</span>
      <h3>宿主端口与共享接入</h3>
      <ul>
        <li><span class="mono">main.js</span> 创建 MCP service，复用本地宿主与配置</li>
        <li>主 Web 服务默认 <b>3888</b>；MCP HTTPS 优先 <b>3922 / 13922 / 23922</b>，冲突后可选空闲端口 —— 候选端口不是多台服务器</li>
        <li>图片上传 <span class="mono">/mcp/images</span> 复用同一 HTTPS 接入与认证，服务端有界处理后交付指定文档</li>
        <li>浏览器执行具体文档动作；Node 端不是 HTML 排版渲染器</li>
      </ul>
    </div>
    <div class="panel" style="border-top-color:var(--purple)">
      <span class="tag">详情 C · 对应主图「两种存储」</span>
      <h3>存储所有者不同</h3>
      <ul>
        <li><b>Node 侧：</b><span class="mono">conversation-bindings.js</span> 持久化 client/sessionKey → canvasId/documentId</li>
        <li><b>浏览器侧：</b>画布文档、快照与沙箱 Widget 均由浏览器持有</li>
        <li>浏览器连接 ID、文档 ID、业务 sessionId 与 HTTPS 传输 session ID 是不同标识</li>
