    <div class="panel" style="--pc:#0f766e;">
      <h3><em>A</em>单宿主与端口</h3>
      <ul>
        <li><b>main.js</b> 创建 MCP service，复用本地宿主与配置</li>
        <li>主 Web 服务默认 <b>3888</b>；MCP HTTPS 优先 <b>3922 / 13922 / 23922</b>，冲突后可选空闲端口</li>
        <li>候选端口是同一 listener 的备选，<b>不是多台服务器</b></li>
        <li>图片上传 <b>/mcp/images</b> 复用同一 HTTPS 接入与认证，经有界处理后交给指定文档</li>
      </ul>
    </div>
    <div class="panel" style="--pc:#6d28d9;">
      <h3><em>B</em>两种存储、多种 ID</h3>
      <ul>
        <li><b>Node 侧</b>：conversation-bindings.js 持久化 client/sessionKey → canvasId/documentId</li>
        <li><b>浏览器侧</b>：文档与快照由浏览器持有，不画成 Node 文件存储</li>
        <li>浏览器连接 ID、文档 ID、业务 sessionId 与 HTTPS 传输 session ID <b>互不相同</b></li>
        <li>虚拟 source path（objects/&lt;id&gt;/widget.html）<b>不是</b>模型电脑上的真实路径</li>
      </ul>
    </div>
    <div class="panel" style="--pc:#6d28d9;">
      <h3><em>C</em>guidance 只读分支</h3>
      <ul>
        <li><b>rpc.js</b> 中为独立只读分支，不经浏览器画布队列、不调用模型</li>
        <li><b>authoring-guidance.js</b>：规则 registry + 惰性正文加载，返回 id/hash/document</li>
        <li><b>schema.js</b> 对 guidance 输入校验，工具 schema 同源</li>
        <li><b>architecture</b> 为独立规则；通用 <b>visual-explorer</b> 只列规则目录，不含其正文</li>
      </ul>
    </div>
    <div class="panel" style="--pc:#c2570a;">
      <h3><em>D</em>Widget 交付与后续编辑</h3>
      <ul>
        <li>外部 AI 给 <b>penecho_present_widget</b> 传 HTML，浏览器沙箱 iframe 内渲染</li>
        <li>后续 <b>read_file / patch_file</b> 围绕同一文档的虚拟源文件工作</li>
        <li><b>bound-operations.js</b> 协调版本/hash、幂等 requestId、虚拟读写与交付</li>
        <li>具体文档动作由浏览器执行；结果/截图沿原通道返回</li>
      </ul>
    </div>
    <div class="panel" style="--pc:#475569;">
