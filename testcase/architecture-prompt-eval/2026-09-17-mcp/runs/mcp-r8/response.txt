<div class="panels">
<section class="panel pa">
<h2><span class="ptag">A</span>传输与接入</h2>
<ul>
<li>stdio 桥 = 轻量 <span class="code">client.js</span>（<span class="code">session-client.js</span>），不是完整 PenEcho 应用。</li>
<li>桥读取<b>共享主机凭据</b>与<b>发现缓存</b>，校验 TLS，经 HTTPS <span class="code">/mcp</span> 复用连接。</li>
<li><span class="code">discovery-client.js</span> / <span class="code">lan-discovery.js</span>：先已知地址与缓存，再按需发现，<b>无常驻发现守护进程</b>。</li>
<li>主机凭据存于 MCP 状态目录，桥端有独立信任资料（图中只画职责）。</li>
</ul>
</section>
<section class="panel pb">
<h2><span class="ptag">B</span>会话与绑定</h2>
<ul>
<li><span class="code">service.js</span> 持有<b>已授权浏览器连接</b>、打开文档目录与画布会话。</li>
<li>持久绑定：<span class="code">client/sessionKey → canvasId/documentId</span>。</li>
<li>浏览器连接 ID、文档 ID、业务 sessionId、HTTPS 传输 session ID <b>互不相同</b>。</li>
<li>HTTP 空闲清理<b>不终止</b>仍开 stdin 的轻量桥；下次调用重连并恢复原文档，<b>不盲目重放</b>可能已提交的写请求。</li>
</ul>
</section>
<section class="panel pc">
<h2><span class="ptag">C</span>浏览器画布运行时</h2>
<ul>
<li>opt-in 浏览器经 WebSocket <span class="code">/api/mcp/canvas</span> 连接；发 hello / 文档 catalog，收 call 返 result；心跳、断线、取消均有处理。</li>
<li>浏览器关闭授权后<b>拒绝</b>外部画布操作。</li>
<li>Widget 在沙箱 iframe 渲染；画布文档与快照由<b>浏览器持有</b>，不是 Node 文件存储。</li>
<li>虚拟源路径（如 <span class="code">objects/&lt;id&gt;/widget.html</span>）<b>不是</b>主机真实文件路径；<span class="code">read_file / patch_file</span> 围绕同一文档的虚拟源工作。</li>
</ul>
</section>
<section class="panel pd">
<h2><span class="ptag">D</span>规则分支与可观测性</h2>
<ul>
<li><span class="code">penecho_get_guidance</span> 从 <span class="code">authoring-guidance.js</span> 读取规则（id/hash/document），<b>独立只读分支</b>：不进画布队列、不调模型。</li>
<li><span class="code">visual-explorer</span> 仅列规则目录；<span class="code">architecture</span> 为独立规则正文。</li>
<li>开启请求日志时，<span class="code">request-trace.js</span> 记录多轮 tool / browser 交互；日志目录与 Agent 日志平行，<b>不是</b>画布源文件。</li>
<li>内置 Agent 复用共用画布操作与 guidance，<b>不是</b>外部 MCP 的必经环节。</li>
</ul>
</section>
